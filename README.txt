MORE / LESS – Web-App

So wird das Spiel für alle erreichbar:
1. Lade den Inhalt dieses Ordners auf einen statischen Webhost (z.B. GitHub Pages, Netlify oder Cloudflare Pages).
2. Öffne danach die erzeugte HTTPS-Adresse im Browser.
3. Auf iPhone/iPad: Safari > Teilen > Zum Home-Bildschirm.

Die Modi Solo, lokales 1vs1, Party, Survival, Blitz, King und Chaos laufen vollständig im Browser.
Die Schaltfläche Online-Lobby ist bewusst nur vorbereitet: echte Raumcodes über mehrere Geräte benötigen ein Echtzeit-Backend (z.B. Supabase/Firebase), damit Spielerzustände sicher synchronisiert werden.
